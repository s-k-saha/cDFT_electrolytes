# Classical Density Functional Theory (cDFT) Solver

A C-based classical Density Functional Theory (cDFT) solver for computing equilibrium density profiles of **n interacting species**.

Currently, the implementation supports **1D geometries**, where the system is assumed to be translationally invariant in the other two spatial dimensions.

For a detailed description of the theoretical framework, derivations, and approximations implemented in the code, see **[Theory.pdf](Theory.pdf)**.

## Supported Interactions

The solver currently includes the following interaction models:

1. **Rosenfeld Fundamental Measure Theory (FMT)** for hard-sphere interactions.

2. **Lennard-Jones (LJ)** interactions

   * ( r_{\min} = 2^{1/6}\sigma )
   * ( r_c = 2.5\sigma )

3. **Electrostatic (ES) interactions**

   * Long-ranged Coulomb interactions.

At present, all attractive interactions are treated within the **Random Phase Approximation (RPA)** framework. This allows the theory to be closed self-consistently and enables the computation of bulk thermodynamic properties, including:

* Equation of state
* Chemical potentials
* Phase coexistence
* Phase diagrams

## Compilation

For the first use on a new computer or server, compile the code by running:

```bash
make
```

from the top-level directory:

```bash
cd cDFT_electrolytes
make
```

The Makefile automatically handles compilation, linking, and generation of the executable.

---

## Running Simulations

To generate data for a new system:

1. Modify the input files:

   * `data/params_geometry.txt`
   * `data/params_system.txt`

2. Run the executable generated in the `exec/` directory.

Simulation outputs will be written to the `data/` directory.
