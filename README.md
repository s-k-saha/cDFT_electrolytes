This system is a C based classical DFT solver that can compute density profiles of n interacting species. Currently its in 1D geometry (physics is invariant in the other two dimensions). 

Interactions that it supports: 

(1) Rosenfeld FMT for hard-spheres 
(2) Lennard-Jones  [rmin=pow(2.,1./6)*sigma, rc=2.5*sigma]
(3) ES-interactions (Long ranged coulomb)

Right now all interactions are Random Phase Approximations. This allow the theory to be closed and self-consistently compute all the bulk thermodynamic quantities incluing the phase diagram.

During first usage in a computer/server, run the command in the terminal: make (while in cDFT_electrolytes) and the compiler takes care of everything.
To generate new data with different parameters, just change the params_geometry.txt and params_system.txt.
